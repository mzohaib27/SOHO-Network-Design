# Cisco SOHO Network Design & Implementation

## Project Overview

This project demonstrates the design and implementation of a Small Office/Home Office (SOHO) network using Cisco Packet Tracer.

The network consists of three departments:

- Admin/IT
- Finance/HR
- Customer Service/Reception

Each department will use a separate VLAN and wireless network. DHCP will provide automatic IPv4 addressing, and router-on-a-stick will enable inter-VLAN communication.

## Project Objectives

- Design a Cisco-based SOHO network.
- Configure VLANs for three departments.
- Configure trunking between the switch and router.
- Implement inter-VLAN routing.
- Configure DHCP for automatic IPv4 addressing.
- Provide wireless access to all departments.
- Verify connectivity and document troubleshooting.
